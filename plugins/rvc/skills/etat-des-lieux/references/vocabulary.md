# Vocabulaire technique — état des lieux

Lexique validé par Antoine. À consulter systématiquement et à enrichir au fil
des EDL si de nouvelles préférences sont validées.

## Sols

| Mauvais (à corriger)         | Bon (à inscrire)                          |
|------------------------------|--------------------------------------------|
| lino, linolium               | linoléum                                   |
| dalles plastiques            | dalles PVC                                 |
| moquette                     | moquette (terme accepté tel quel)          |
| carrelage cassé              | carrelage avec carreaux cassés / fissurés  |
| ciment                       | dalle béton                                |
| sol pas propre               | sol sale / très sale / poussiéreux         |
| griffé                       | avec traces de griffures                   |
| brûlure                      | brûlures                                   |
| auréoles                     | auréoles                                   |
| trous                        | trous (au pluriel si plusieurs)            |

**Qualifications d'état préférées** :

- `à l'état d'usage` (état normal d'occupation, pas de défaut majeur)
- `dégradé`
- `en mauvais état`
- `en très mauvais état`

**Qualifications de propreté préférées** :

- `propre`
- `sale`
- `très sale`
- `ensemble très sale`
- `poussiéreux`

|------------------------------|--------------------------------------------|
| porte qui marche             | porte ouvrant et fermant correctement      |
| porte cassée                 | porte dégradée / porte en mauvais état     |

| poignée bouge                | poignée avec jeu                           |

**Précisions à mentionner systématiquement** :

- Provenance / sens (`depuis le palier`, `depuis le couloir`, `depuis la cuisine`, `depuis le séjour`, `depuis le salon`)
- État de fonctionnement (`ouvrant et fermant correctement` / `ne fermant pas correctement` / `dégondée`)
- Défauts visibles (taches, rayures, manques de matière, traces de réparation, traces d'enduit, inscriptions, écaillements)

## Tournures à éviter (interprétations / conclusions)

À **proscrire systématiquement** dans un EDL :

- *« manifestement »*
- *« visiblement »*
- *« semble »*
- *« paraît »*
- *« semble-t-il »*
- *« on dirait »*
- *« sans doute »*
- *« probablement »*
- *« il est évident que »*
- *« il faut »* / *« il faudra »*
- *« à refaire »* / *« à remplacer »* / *« à réparer »*
- *« usure normale »* / *« usure anormale »*
- *« mauvais entretien »* / *« absence d'entretien »*
- *« le locataire a »* + verbe d'action interprétative

Le constat ne juge pas, il décrit.
