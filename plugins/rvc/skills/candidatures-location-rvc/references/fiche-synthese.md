# Gabarit de la fiche de synthèse PDF

Une fiche **par candidat**, à produire avec le skill `pdf`. Format A4,
sobre, lisible en un coup d'œil. Nom de fichier :
`fiche_[NomCandidat]_[bien]_[AAAA-MM-JJ].pdf`.

La fiche est un document **interne** (données personnelles) : factuel, daté.

## Structure imposée

```
RVC IMMOBILIER — Fiche de synthèse de candidature locative
Bien : [type, adresse] — Loyer : [X] € CC ([HC] € + [charges] € de charges)
Date d'analyse : [JJ/MM/AAAA]

────────────────────────────────────────────
NOTE : [note]/100        NIVEAU : [À retenir / À examiner / À écarter]
────────────────────────────────────────────

1. IDENTITÉ DU CANDIDAT
   Nom, prénom – date de naissance
   Co-titulaire(s) éventuel(s)
   Situation : [salarié CDI / CDD / indépendant / retraité / étudiant…]

2. RESSOURCES ET SOLVABILITÉ
   Revenus nets du foyer : [montant] €/mois
   Ratio revenus / loyer CC : [x,x]×  (cible ≥ 3×)
   Garant : [oui/non] – revenus [montant] € – ratio [x,x]× – [solide/correct/faible]

3. PIÈCES DU DOSSIER
   Tableau : Pièce attendue | Reçue ? | Conforme ? | Remarque
   (identité, domicile, situation pro, ressources — candidat ; idem garant)
   Pièces manquantes : [liste ou « aucune »]

4. CONTRÔLE DE COHÉRENCE / FIABILITÉ
   Alertes : [niveau] description… (ou « Aucune incohérence détectée »)

5. DÉTAIL DE LA NOTE
   Solvabilité …… /40
   Garant ……………… /20
   Stabilité pro …… /15
   Complétude ……… /15
   Fiabilité ………… /10
   TOTAL ……………… /100

6. SYNTHÈSE / RECOMMANDATION
   2–3 phrases : points forts, points de vigilance, action conseillée.
   Rappel : décision finale au propriétaire.
```

Conseils de mise en page : bandeau de note coloré (vert ≥70 / orange 50–69 /
rouge <50), tableau des pièces avec coches, pied de page « Document interne RVC
Immobilier — données confidentielles ».
